## Platform-Specific Guidelines

### Instagram

**Feed Posts:**
- **Best format**: Portrait (1080 x 1350) - takes up more screen space
- **Safe zone**: Keep important text/elements away from edges
- **Carousel**: Up to 10 images, all same dimensions
- **Text overlay**: Use high contrast, keep minimal

**Stories & Reels:**
- **Safe zones**: Avoid top 250px (profile) and bottom 250px (buttons)
- **Duration**: Stories 15s max, Reels 90s max
- **Sound**: 60% watch with sound on

**Best Practices:**
- Bright, vibrant colors perform well
- Faces increase engagement by 38%
- User-generated content style outperforms polished content
- Carousel posts get 1.4x more reach

---

### LinkedIn

**Post Types:**
- **Single image**: Most common, 1200 x 628
- **Document/PDF**: Carousel-style, up to 300 pages
- **Video**: Native performs 5x better than links

**Professional Guidelines:**
- Clean, professional aesthetic
- Blue tones perform well (matches LinkedIn brand)
- Charts/infographics get high engagement
- Text-heavy images work for thought leadership

**Banner Tips:**
- Keep important elements in center (mobile crop)
- Personal banners: show personality
- Company banners: brand consistent

---

### Facebook

**Engagement Tips:**
- Video gets 59% more engagement
- Images with faces get 38% more likes
- Questions in images drive comments
- Carousel ads: 10x more clicks than single

**Cover Photo:**
- Different crops on mobile vs desktop
- Safe zone: center 640 x 312
- No text in bottom-left (overlaps with buttons)

### Twitter/X

**Best Practices:**

## Design Principles for Engagement

### Color Psychology

| Color | Emotion | Best For |
|-------|---------|----------|
| Red | Urgency, excitement | Sales, CTAs |
| Blue | Trust, calm | Corporate, tech |
| Green | Growth, health | Wellness, finance |
| Yellow | Optimism, warmth | Youth, food |
| Orange | Energy, fun | Entertainment |
| Purple | Luxury, creativity | Premium brands |
| Black | Sophistication | Luxury, fashion |
| White | Clean, simple | Minimalist brands |

### Typography Rules

1. **Maximum 2 fonts** per design
2. **Headline**: Bold, attention-grabbing
3. **Body**: Clean, readable
4. **Minimum size**: 30px for social media (viewable on mobile)
5. **Contrast**: Dark text on light background or vice versa

### Composition Guidelines

1. **Rule of thirds**: Place key elements at intersections
2. **White space**: Don't overcrowd - let designs breathe
3. **Focal point**: One clear main element
4. **Hierarchy**: Guide eye from most to least important
5. **Consistency**: Same style across campaign

### Call-to-Action (CTA) Best Practices

- **Be specific**: "Download Free Guide" > "Click Here"
- **Create urgency**: "Limited time" / "Today only"
- **Make it visible**: Contrasting color, prominent placement
- **One CTA per design**: Don't confuse viewers

## Quick Design Formulas

### Quote Graphics
```
Background: Solid color or subtle gradient
Font: Large, centered quote
Attribution: Smaller, below quote
Logo: Bottom corner
```

### Announcement Posts
```
Top: Attention-grabbing headline
Middle: Key details (what, when, where)
Bottom: CTA button
Logo: Top corner
```

### Product Showcases
```
Product: Center, high-quality image
Features: Bullet points or icons
Price: Prominent if relevant
CTA: "Shop now" / "Learn more"
```

### Testimonials
```
Quote: Large, with quotation marks
Photo: Customer headshot (if available)
Name/Title: Below quote
Logo: Corner
Star rating: If applicable
```

### Carousel/Slideshow
```
Slide 1: Hook (question or bold statement)
Slides 2-8: Value (tips, steps, info)
Last Slide: CTA (follow, save, share)
```

## File Format Guidelines

| Format | Best For | Notes |
|--------|----------|-------|
| PNG | Graphics with transparency | Larger file size |
| JPG | Photos | Lossy compression |
| GIF | Animations | Limited colors |
| MP4 | Videos | Universal support |
| PDF | Documents, print | Vector-friendly |
| SVG | Logos, icons | Scalable |

### Export Quality Settings

- **Social media**: Standard quality, optimize for web
- **Print**: High quality, 300 DPI minimum
- **Presentations**: High quality for clarity
- **Web**: Optimize for fast loading

## Integration with Workflows

This design reference is designed to work with:

1. **Canva Skills** - Create designs using dimensions above
2. **Content Generation** - Ideas for posts
3. **Outreach Skills** - Attach designs to emails
4. **Automation** - Batch design creation

### Workflow Example

```
User Request: "Create LinkedIn post about our new product"

1. Design Skill: Determines dimensions (1200 x 628)
2. Content Generator: Creates headline and body text
3. Canva API: Creates design with brand colors
4. Export: Downloads as PNG
5. Outreach Skill: Attaches to email campaign
```
