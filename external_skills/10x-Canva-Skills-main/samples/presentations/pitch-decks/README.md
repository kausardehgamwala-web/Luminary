# Pitch Deck Samples

Add your pitch deck and business presentation samples here.

## What to Include

- Investor pitch decks
- Sales presentations
- Company overviews
- Product demos

## How to Add

1. Export slides as individual images or full PDF
2. Include slide structure outlines
3. Note successful presentation elements

```
pitch-decks/

├── sales_deck/
│   └── ...

```

## Key Slides to Include

1. Title/Cover slide
2. Problem statement
3. Solution
4. Market opportunity
5. Business model
