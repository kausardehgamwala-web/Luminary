# Color Palettes

Store your preferred color palettes here.

## How to Add

Create JSON files with your color schemes:

```json
{
  "name": "Ocean Breeze",
  "colors": {
    "primary": "#2E86AB",
    "secondary": "#A23B72",
    "accent": "#F18F01",
    "background": "#F5F5F5",
    "text": "#1A1A1A"
  },
  "use_case": "Summer campaigns"
}
```

## File Naming

Use descriptive names:
- `brand-primary.json` - Main brand colors
- `summer-campaign.json` - Seasonal palette
- `dark-mode.json` - Dark theme colors

The content generator skill will reference these when creating designs.
