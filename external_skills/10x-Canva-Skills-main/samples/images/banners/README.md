# Banner Samples

Add banner and cover design samples here.

## What to Include

- Website banners
- Social media covers (Facebook, LinkedIn, Twitter)
- YouTube channel art
- Email headers
- Ad banners

## Common Dimensions

- Facebook Cover: 820x312
- LinkedIn Banner: 1584x396
- Twitter Header: 1500x500
- YouTube Banner: 2560x1440
- Website Hero: Various (1920xN)

## How to Add

Export your best banners and name them by platform/purpose:
- `facebook_cover_brand.png`
- `linkedin_banner_professional.png`
- `youtube_channel_art.png`
