# Poster Samples

Add your poster design samples here.

## What to Include

- Event posters
- Promotional posters
- Infographic posters
- Movie/show style posters

## How to Add

1. Export posters from Canva as PNG or PDF
2. Include various sizes you commonly use
3. Add notes about design elements you like

## File Naming

Use descriptive names:
- `event_poster_modern.png`
- `sale_poster_bold.png`
- `infographic_data_viz.png`
