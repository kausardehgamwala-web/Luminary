# Templates

Store custom template references here.

## Purpose

Keep track of your favorite Canva templates or custom templates you've created.

## How to Add

Create a `templates.json` file:

```json
{
  "social_media": {
    "instagram_post": "template_id_123",
    "instagram_story": "template_id_456",
    "facebook_post": "template_id_789"
  },
  "presentations": {
    "pitch_deck": "template_id_abc",
    "quarterly_report": "template_id_def"
  },
  "marketing": {
    "flyer": "template_id_ghi",
    "poster": "template_id_jkl"
  }
}
```

## Template Screenshots

Add screenshots of your templates for reference:
- `instagram_template.png`
- `pitch_deck_cover.png`

This helps the AI understand your template preferences.
