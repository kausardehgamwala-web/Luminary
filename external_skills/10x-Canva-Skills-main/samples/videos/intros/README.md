# Intro/Outro Video Samples

Add your video intro and outro samples here.

## What to Include

- YouTube channel intros
- Podcast intros
- Presentation openers
- Video outros with CTAs
- Logo animations

## How to Add

Include:
- Keyframe screenshots
- Duration notes
- Animation style preferences
- Sound effect preferences

## Example Structure

```
intros/
├── youtube_intro/
│   ├── frame_01_logo.png
│   ├── frame_02_animation.png
│   ├── frame_03_tagline.png
│   └── notes.txt
├── podcast_intro/
│   └── ...
└── style_notes.txt
```

## Typical Durations

- Logo sting: 2-3 seconds
- Channel intro: 3-5 seconds
- Full intro: 5-10 seconds
- Outro: 5-15 seconds
