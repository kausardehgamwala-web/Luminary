# Reels/Short Video Samples

Add your short-form video samples here.

## What to Include

- Instagram Reels
- TikTok videos
- YouTube Shorts
- Short promotional clips

## How to Add

Since video files are large, add:
- Thumbnail images
- Keyframe screenshots
- Storyboard outlines
- Text overlay examples

## Example Structure

```
reels/
├── product_reveal/
│   ├── thumbnail.png
│   ├── keyframe_01.png
│   ├── keyframe_02.png
│   ├── keyframe_03.png
│   └── storyboard.txt
└── style_notes.txt
```

## Style Notes to Include

- Typical duration (15s, 30s, 60s)
- Text animation preferences
- Music/audio style
- Transition types
- Hook strategies
