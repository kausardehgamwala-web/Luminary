# Fonts

Document your font preferences here.

## How to Add

Create a `preferences.json` file:

```json
{
  "headings": {
    "primary": "Montserrat",
    "secondary": "Playfair Display",
    "weights": ["Bold", "SemiBold"]
  },
  "body": {
    "primary": "Open Sans",
    "secondary": "Lato",
    "weights": ["Regular", "Medium"]
  },
  "accent": {
    "script": "Dancing Script",
    "display": "Bebas Neue"
  },
  "avoid": ["Comic Sans", "Papyrus"]
}
```

## Font Pairing Notes

Add a `pairings.md` file with your favorite combinations:

```markdown
## Heading + Body Pairings

1. Montserrat + Open Sans (modern, clean)
2. Playfair Display + Source Sans Pro (elegant)
3. Oswald + Lato (bold, impactful)
```

These preferences guide the content generator skill.
